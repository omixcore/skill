This file provides reusable author-information templates for manuscript drafts, title pages, cover letters, and submission systems. The first set is the default template. Verify the actual author contributions, author order, affiliations, and corresponding-author arrangements for each manuscript before submission.

**中文版**

- 默认作者顺序：Junyue Wang、Fei Liang。
- 默认单位对应关系：Junyue Wang¹ 对应山东农业大学农学院；Fei Liang² 对应河南大学。
- 默认通讯作者：Fei Liang，邮箱 fyliangfei@163.com。
- 不得自行添加共同第一作者、共同通讯作者或其他贡献声明；只有在实际贡献和作者确认支持时才添加。
- 作者邮箱、单位名称及地址按本文件记录保留；投稿前核对机构官方英文名称、邮编、城市和通讯邮箱。
- 如果具体论文的作者、顺序、贡献、单位或通讯作者发生变化，必须按该论文实际情况更新，不能机械套用默认模板。
- 期刊对作者信息的格式要求不同时，可调整标点、上标和字段顺序，但不得改变作者身份或贡献事实。
- 默认模板中未提供的作者邮箱、ORCID、作者贡献和基金信息不得自行编造。
