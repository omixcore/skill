This file provides a reusable author-information template for manuscript drafts, title pages, cover letters, and submission systems. The English text is the submission-ready template; the Chinese text is provided for reference and verification. Confirm the actual author contributions, author order, affiliations, and corresponding-author arrangements for each manuscript before submission.
