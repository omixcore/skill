# 文献引用真实性与支撑性核查规范 / Reference Authenticity and Claim-Support Verification

适用于论文正文、综述、引言、讨论、图注、补充材料及其他需要引用学术文献的写作任务。**任何文献都必须先核查真实性，再核查其是否合理且足以支撑对应语句，完成两步核查后才能引用。**

## 1. 第一步：核查文献真实性 / Verify That the Reference Exists

引用前先确认文献真实存在，不能仅凭搜索摘要、他人参考文献列表、AI 生成内容或看似合理的 DOI 推断文献存在。

至少核对以下书目信息：

- 论文标题（Title）
- 作者及作者顺序（Authors）
- 期刊或出版来源（Journal / Publisher）
- 发表年份（Publication year）
- DOI、PMID、文章编号或其他可追溯标识（如适用）

优先通过以下来源交叉核查：

1. 期刊出版社的正式论文页面及 DOI 注册信息。
2. Crossref、PubMed、Web of Science、Scopus、Google Scholar 等学术检索或索引数据库。
3. 相关学科的权威数据库、学术机构或正式出版平台。

核查注意事项：

- DOI 必须能够解析，并且解析到的标题、作者和出版信息与拟引用文献一致。
- 检查是否存在更正、撤稿、关注声明（Expression of Concern）或版本更新。
- 预印本、会议摘要、学位论文和正式同行评审论文应准确标明文献类型，不能混为一谈。
- 如果文献记录不完整或无法找到可靠记录，标记为“真实性未确认”，不得将其作为已核实的正式文献引用。
- 不得编造作者、标题、期刊、年份、卷期页码、DOI 或 PMID。

## 2. 第二步：核查文献是否能够支撑具体语句 / Verify Claim-Level Relevance and Support

文献真实存在，并不代表它可以支持当前句子。必须将引用与其所支持的具体陈述逐条对应核查。

重点检查：

- **研究问题是否一致**：文献研究的科学问题是否与当前语句一致，而不是仅仅出现相同关键词。
- **研究对象是否一致**：物种、品种、细胞类型、组织、发育阶段、处理条件或研究人群是否匹配。
- **研究内容是否一致**：文献是否实际研究了所述基因、蛋白、通路、表型、机制或方法。
- **证据类型是否合适**：实验验证、遗传学证据、组学关联、计算预测、综述观点和假说推测的证据强度不同，不得相互替代。
- **结论强度是否匹配**：相关性不能写成因果性；表达变化不能单独证明功能；预测结果不能写成实验验证；特定条件下的结论不能无依据地推广到所有物种或环境。
- **原文是否真正支持**：检查正文中相关结果、图表、方法和讨论，而不只看标题、摘要或关键词。
- **是否存在相反或限制性证据**：不能只挑选支持预期观点的文献；应关注原文中的反例、限定条件和作者明确指出的局限。

## 3. 第三步：建立“语句—证据”对应关系 / Map Each Claim to Its Evidence

引用应以具体语句或具体事实为单位核查，而不是以整段文字为单位笼统判断。

建议建立以下核查记录：

| 待引用语句或主张 | 文献真实性 | 原文证据位置 | 支撑程度 | 处理方式 |
| --- | --- | --- | --- | --- |
| 当前稿件中的具体陈述 | 已核实 / 未核实 | 页码、章节、图表或补充材料 | 直接支持 / 部分支持 / 不支持 / 存在矛盾 | 保留引用 / 改写语句 / 更换文献 / 删除引用 |

支撑程度的判断：

- **直接支持（Direct support）**：原文数据或结论直接回答该语句所表达的主张，可正常引用。
- **部分支持（Partial support）**：文献仅支持语句的一部分、特定条件或较弱版本，应缩小语句范围或降低措辞强度。
- **不支持（No support）**：文献没有提供对应证据，即使主题相近也不能引用来支撑该语句。
- **存在矛盾（Contradictory evidence）**：文献结果与语句相反，应如实处理，不能将其作为支持性引用。

## 4. 第四步：确认后再引用 / Cite Only After Verification

只有完成真实性和支撑性两步核查后，才能将文献放入正文或参考文献列表。

- 优先引用直接提供证据的原始研究；综述可用于概述领域背景，但不能替代关键机制或实验事实的原始证据。
- 对多个子主张，分别配置能够支持各自内容的文献，不用一篇文献笼统支撑整句中所有不同结论。
- 引用位置应紧跟其实际支持的语句，避免引用范围含混。
- 如果文献只支持有限条件，应在句子中明确物种、组织、阶段、处理或研究范围。
- 不为追求引用数量而堆砌文献；优先选择最直接、可靠且相关的证据。
- 如果只能核实文献存在，但无法访问或检查足够的原文内容，应明确标注“支撑性尚未核实”，不能声称已确认该文献支持该语句。
- 发现原有引用不合理时，应指出问题并建议删除、替换或改写对应语句，而不是保留错误引用。

## 5. 写作交付前检查清单 / Pre-submission Checklist

- [ ] 每条参考文献均有可追溯的真实记录。
- [ ] 标题、作者、期刊、年份和 DOI 等书目信息一致。
- [ ] 已检查撤稿、更正或其他出版状态信息（适用时）。
- [ ] 每条引用均对应到具体语句或具体主张。
- [ ] 已检查原文结果、图表或相关章节，而不只是标题和摘要。
- [ ] 研究对象、条件、方法和证据类型与语句匹配。
- [ ] 语句强度没有超出文献证据强度。
- [ ] 已考虑相反证据、研究限制和适用范围。
- [ ] 无法核实的文献或支撑关系已明确标注，未被伪装成已验证引用。
- [ ] 正文引用与文末参考文献列表能够一一对应。

**核心顺序：先确认文献真实存在，再确认原文确实支持具体语句，最后才引用。文献真实不等于引用合理，主题相关也不等于证据支持。**
