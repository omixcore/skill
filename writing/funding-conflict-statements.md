# 默认基金与利益冲突声明 / Default Funding and Conflict of Interest Statements

本文件提供论文 Funding Statement 和 Conflict of Interest / Competing Interests 的常用模板。英文声明用于投稿，中文内容用于理解和核对；每篇论文使用前必须确认实际资助关系、利益冲突情况及期刊格式要求。

This file provides reusable templates for Funding Statements and Conflict of Interest / Competing Interests declarations. Use the English statements for submission and the Chinese translations for reference. Verify the actual funding relationships, competing interests, and journal requirements for each manuscript.

## 1. Funding Statement / 基金资助声明

### English Submission Text / 英文投稿文本

The author(s) declared that financial support was received for this work and/or its publication. This work was supported by the Henan Province Science and Technology Research Project (Grant No. 252102310465) and the Henan Private Universities Characteristic Development Program (Grant No. SJ2025MBTS03).

### 中文对照 / Chinese Translation

作者声明，本研究及/或其发表获得了经费支持。本研究获得河南省科技研究项目（项目编号：252102310465）和河南省民办高校特色发展计划（项目编号：SJ2025MBTS03）的资助。

### Funding Sources / 基金项目

- **English:** Henan Province Science and Technology Research Project — Grant No. 252102310465.
  **中文：** 河南省科技研究项目——项目编号：252102310465。
- **English:** Henan Private Universities Characteristic Development Program — Grant No. SJ2025MBTS03.
  **中文：** 河南省民办高校特色发展计划——项目编号：SJ2025MBTS03。

### Usage Rules / 使用规则

**中文版**

- 将以上内容作为常用默认基金声明。
- 每篇论文提交前，核实该研究是否实际获得上述基金支持，以及基金是否支持研究工作、论文发表或两者。
- 如果仅有部分基金支持该研究，应删除未实际提供资助的项目。
- 如有新增基金，按真实资助情况补充基金名称和编号。
- 期刊要求使用特定 Funding 格式时，按期刊要求调整措辞，但不得改变资助事实。

**English Version**

- Use this text as the default funding statement template.
- Before submission, verify whether the study actually received support from the listed grants and whether the support covered the research, publication, or both.
- Remove any grant that did not support the specific work.
- Add other grants only when their support is factually confirmed, using the correct official names and grant numbers.
- Adapt the wording to the journal's required Funding format without changing the underlying funding facts.

## 2. Conflict of Interest / Competing Interests / 利益冲突声明

### English Submission Text / 英文投稿文本

The authors declare that they have no competing interests.

### 中文对照 / Chinese Translation

作者声明不存在需要披露的竞争性利益。

### Usage Rules / 使用规则

**中文版**

- 在无需要披露的竞争性利益时，使用以上默认声明。
- 如期刊指定使用 `Conflict of Interest`、`Competing Interests` 或其他标题，按期刊格式调整标题。
- 如作者存在需要披露的财务、职业、个人或其他相关利益关系，应根据实际情况进行披露，不得使用不真实的“无利益冲突”声明。

**English Version**

- Use this default statement only when the authors have no competing interests that require disclosure.
- If the journal specifies the heading `Conflict of Interest`, `Competing Interests`, or another format, follow the journal's instructions.
- If any author has a financial, professional, personal, or other relevant interest that requires disclosure, report it accurately rather than using an untrue no-conflict statement.

## 3. Submission Checklist / 投稿前检查清单

**中文版**

- [ ] 核对基金名称、编号和实际资助关系。
- [ ] 核对是否需要删减或增加基金项目。
- [ ] 核对作者是否确实不存在需要披露的竞争性利益。
- [ ] 核对目标期刊的声明标题、格式及措辞要求。

**English Version**

- [ ] Verify the official grant names, grant numbers, and actual funding relationships.
- [ ] Confirm whether any grant should be removed or added.
- [ ] Confirm that no author has a competing interest requiring disclosure.
- [ ] Check the target journal's required headings, format, and wording.
